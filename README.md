# Claims Investigation Agent — Eval-Driven Development Workshop

A technical workshop demonstrating eval-driven development for a multi-tool
LangGraph agent in an insurance context.

## Setup
```bash
cp .env.example .env
# Fill in your API keys
uv sync
```

## Structure
- `data/` — Mock data sources in realistic formats (md, csv, json)
- `agent/` — LangGraph agent, tools, and output schema (coming next)
- `evals/` — Evaluators and dataset (coming next)
- `notebooks/` — Workshop demo walkthrough (coming next)
